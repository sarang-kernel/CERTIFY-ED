# docs/results/

Result documents of the code: the evidence runs, the development tracks and the inspection of the mutation survivors.
Until 20 November 2026 these files were at the root of the repository. Commits before that date have them there, and
documents written before it cite them by file name only; the names did not change.

| file | what it records |
|---|---|
| `RESULT_D-05.md` | GPU products for S2 (D-05): measurements and bit identity on the device |
| `RESULT_backlog-proofs.md` | track/backlog-proofs: derivations of the UNVERIFIED backlog (D-59) |
| `RESULT_candidate_run.md` | candidate reproduction run: what was re-derived next to the reference run |
| `RESULT_evidence_run_3.1.0.md` | evidence run of 3.1.0 (Windows) against the 3.0.0 run (Linux) |
| `RESULT_evidence_run_3.2.1.md` | evidence run of 3.2.1 (`results/run_full_20261105`) against 3.1.0 |
| `RESULT_evidence_run_3.2.2.md` | evidence run of 3.2.2 (`results/run_full_20261112`) against 3.2.1 |
| `RESULT_evidence_run_3.2.3.md` | evidence run of 3.2.3 (`results/run_full_20261112b`) against 3.2.1 |
| `RESULT_figures.md` | figures track (`track/figures`) |
| `RESULT_integration_3.2.md` | integration of roadmap Waves 0 and 1 into `dev/3.2`, with the 3.2 mutation sample |
| `RESULT_new-statements.md` | track of new statements (C-03, C-04, E-04, C-12, C-13, E-07) |
| `RESULT_props_proofs.md` | track/props-proofs (Propositions 14 to 16, Lemma 17; C-06, C-16) |
| `RESULT_scale.md` | track/scale (D-01, D-02) |
| `RESULT_variational.md` | track/variational (E-05, E-03, first part of C-07) |
| `RESULT_whole_spectrum.md` | track/whole-spectrum (C-17, C-14, D-08, A-06, C-15) |
| `E6_inspection_worksheet_3.2.0.md` | E6 inspection worksheet of the 3.2.0 evidence run (the 3.2 mutation survivors) |

Two other files moved on the same day: the roadmap summary `ROADMAP.md` is now `docs/roadmap/ROADMAP.md`, and
`HASH_MAP.csv` (the commit ids before and after the history rewrite of 21 October 2026, decision D-48) is now
`docs/project/HASH_MAP.csv`. The copies of the 3.2.2 and 3.2.3 result documents that were kept in
`docs/project/sources/runs/` were removed; the files here are the current ones (the 3.2.2 document has the note on
single-precision inputs that the copy lacked).
