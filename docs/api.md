# API overview

Generated by `docs/make_api.py` from the docstrings of the public names.

## Model specification

* `LocalSpace(kind: 'str', q: 'int', spin: 'str' = '', convention: 'str' = '', n_max: 'int' = 0, jw_string: 'str' = '') -> None`  
  LocalSpace(kind: 'str', q: 'int', spin: 'str' = '', convention: 'str' = '', n_max: 'int' = 0, jw_string: 'str' = '')
* `ModelSpec(...)`  
  ModelSpec(n_sites: 'int', local: 'LocalSpace', terms: 'List[Term]', site_order: 'str' = 'site0_msb', state_order: 'str' = 'descending', name: 'str' = '', parameters: 'Dict[str, Any]' = <factory>, notes: 'str' = '')
* `spec_from_quspin(static: 'Sequence', basis, n_sites: 'int' = None, **kw) -> 'ModelSpec'`  
  Build a ModelSpec from a QuSpin static list and basis (full-space semantics).
* `heisenberg_chain(...)`  
  H = sum_<ij> J [ (S+_i S-_j + h.c.)/2 + Delta Sz_i Sz_j ] (+ J2 next-nearest).
* `tfim_chain(N: 'int', J: 'float' = 1.0, h: 'float' = 1.0, boundary: 'str' = 'periodic') -> 'ModelSpec'`  
  H = -J sum sigma^z_i sigma^z_{i+1} - h sum sigma^x_i (Pauli convention).
* `heisenberg_square(Lx: 'int', Ly: 'int', J: 'float' = 1.0, J2: 'float' = 0.0, boundary: 'str' = 'periodic') -> 'ModelSpec'`  
  H = J sum_<ij> S_i.S_j (+ J2 on next-nearest neighbours) on an Lx x Ly square lattice, sites y*Lx + x.
* `spinless_fermion_chain(N: 'int', t: 'float' = 1.0, V: 'float' = 0.0, mu: 'float' = 0.0, boundary: 'str' = 'open') -> 'ModelSpec'`  
  H = -t sum (c+_i c_j + h.c.) + V sum n_i n_j - mu sum n_i.
* `bose_hubbard_chain(N: 'int', n_max: 'int', t: 'float' = 1.0, U: 'float' = 1.0, boundary: 'str' = 'open') -> 'ModelSpec'`  
  H = -t sum (b+_i b_j + h.c.) + U/2 sum n_i (n_i - 1), bosons with cutoff n_max.
* `spin1_heisenberg_chain(N: 'int', J: 'float' = 1.0, D: 'float' = 0.0, boundary: 'str' = 'periodic') -> 'ModelSpec'`  
  Spin-1 chain H = J sum S_i.S_{i+1} + D sum (S^z_i)^2.

## Reference operators and sectors

* `build_bitwise(spec: 'ModelSpec', states: 'Optional[StateSet]' = None, return_leak: 'bool' = False)`  
  Build H restricted to `states` (default: full space) by digit arithmetic.
* `build_kron(spec: 'ModelSpec') -> 'sp.csr_matrix'`  
  Reference matrix from Kronecker products of the dense local matrices (independent of build_bitwise).
* `cross_construct(spec: 'ModelSpec', kron_max_dim: 'int' = 65536) -> 'Dict[str, object]'`  
  Build H by both paths and compare. Returns a report dict.
* `SpecOperator(spec: 'ModelSpec', states: 'Optional[StateSet]' = None)`  
  Matrix-free H (and |H| entrywise-dominating operator) defined by a spec.
* `StateSet(states_asc: 'np.ndarray', order: 'str', label: 'str' = 'full') -> None`  
  A set of basis states (integers, site0_msb encoding) with an index map.
* `full_state_set(spec: 'ModelSpec') -> 'StateSet'`  
  All basis states of the spec (integer encoding, site 0 most significant).
* `u1_state_set(spec: 'ModelSpec', total: 'int', label: 'str' = '') -> 'StateSet'`  
  States whose digit sum equals `total` (e.g. N_up for spin-1/2).
* `magnetization_state_set(spec: 'ModelSpec', two_Sz: 'int') -> 'StateSet'`  
  Spin models: fixed total S^z (given as 2*S^z to stay integral).
* `translation(spec: 'ModelSpec') -> 'CyclicSymmetry'`  
  T: site i -> i+1 (mod N). Fermions acquire (-1)^{(n_f-1) n_{N-1}}.
* `spin_flip(spec: 'ModelSpec') -> 'CyclicSymmetry'`  
  Global flip m -> -m on every site (order 2). Spin models only.
* `reflection(spec: 'ModelSpec') -> 'CyclicSymmetry'`  
  Site i -> N-1-i (order 2). Bosons/spins only (fermionic sign omitted).
* `cyclic_isometry(states: 'StateSet', g: 'CyclicSymmetry', j: 'int', drop_tol: 'float' = 1e-10) -> 'sp.csr_matrix'`  
  Isometry onto the character-j subspace of g inside span(states).
* `sector_matrix(H: 'sp.spmatrix', V: 'sp.spmatrix') -> 'sp.csr_matrix'`  
  Sector block V^H H V of an isometry V.

## Certification

* `Claim(...)`  
  A claimed spectral result, as handed over by a producer.
* `Options(...)`  
  Options(model_fidelity: 'bool' = True, kron_cross_check_max_dim: 'int' = 16384, reference_max_dim: 'int' = 4194304, inertia: 'bool' = True, inertia_method: 'str' = 'auto', inertia_max_dim: 'int' = 60000, gap_fractions: 'Sequence[float]' = (0.9, 0.5, 0.2, 0.05), kato_temple: 'bool' = True, eigenspaces: 'str' = 'clusters', cluster_tol: 'float' = 0.0, observables: 'Dict[str, Any]' = <factory>, symmetries: 'Dict[str, Tuple[np.ndarray, Optional[float]]]' = <factory>, corroborate: 'Sequence[str]' = (), store_eigenvectors: 'bool' = False, probe_vectors: 'int' = 3, exact_recheck: 'bool' = False, exact_max_dim: 'int' = 4000, seed: 'int' = 12345, preset: 'Optional[str]' = None, only: 'Optional[Sequence[str]]' = None, skip: 'Sequence[str]' = (), narrowing_reason: 'str' = '', budget_seconds: 'Any' = None, budget_mb: 'Optional[float]' = None, temperatures: 'Sequence[float]' = (), whole_spectrum: 'bool' = False, correlations: 'Dict[str, Any]' = <factory>, degeneracy: 'bool' = True, underflow_check: 'bool' = True, progress: 'Any' = False)
* `certify(claim: 'Claim', spec: 'Optional[ModelSpec]' = None, options: 'Optional[Options]' = None) -> 'Certificate'`  
  Certify a claimed spectrum against a declared model: statements S1-S6 (see the module docstring), returned as a Certificate.
* `quick(H, w, V=None, spec: 'Optional[Any]' = None, kind: 'str' = 'lowest', **options)`  
  Certify the claim "w (with vectors V) are the `kind` eigenpairs of H" in one call.
* `Certificate(body: 'Dict[str, Any]', arrays: 'Optional[Dict[str, np.ndarray]]' = None)`  
  A certificate: body (statements, evidence, claim, subject, environment) and arrays, with canonical-JSON hashing for integrity (save/load/verify_integrity, HDF5 export).
* `OperatorAdapter(op, norm_bound: 'Optional[float]' = None)`  
  Uniform access to H x, |H| |x| bounds and ||H||_2 bounds.
* `enclose(adapter: 'OperatorAdapter', mu: 'Sequence[float]', X: 'Optional[np.ndarray]') -> 'EnclosureSet'`  
  Certified intervals for claimed eigenpairs (mu_i, x_i) of the stored operator.
* `kato_temple(adapter: 'OperatorAdapter', x: 'np.ndarray', alpha: 'float', beta: 'float')`  
  Certified [lo, hi] for the unique eigenvalue in (alpha, beta), or None if the hypotheses cannot be verified (theta not safely inside, or margins smaller than the residual).
* `inertia_count(A, sigma: 'float', method: 'str' = 'auto', dense_max: 'int' = 4096) -> 'InertiaResult'`  
  Inertia count with backward-error bound. If the factorization cannot be completed for lack of memory (MemoryError) or SuperLU reports an internal failure (SystemError, which SciPy raises when SuperLU's allocation fails), the result is inconclusive with ``resource_failure=True``; the certificate then reports completeness as NOT_CHECKED rather than failing.
* `probe_float_environment() -> 'dict'`  
  Run-time test of the hypotheses behind the standard-model bounds, in this process.

## Certificate methods (3.2)

* `Certificate.summary(self) -> 'str'`  
  One sentence: what was certified and what was not (statement counts by status, the largest S2 radius, whether completeness holds and with which gap). `report()` is the full multi-line text.
* `Certificate.report(self) -> 'str'`  
  Full multi-line text: subject, claim, every statement with its summary, scope, not-verified list.
* `Certificate.methods_paragraph(self, style: 'str' = 'plain') -> 'str'`  
  Methods-section paragraph with every number taken from this certificate (certify_ed.report).
* `Certificate.statement(self, sid: 'str') -> 'Optional[dict]'`  
  The statement record with this id, or None.
* `Certificate.counts_by_status(self) -> 'Dict[str, list]'`  
  status -> short ids ('S1', ...) of the statements with that status, in certificate order.
* `Certificate.max_radius(self) -> 'Optional[float]'`  
  Largest certified S2 radius (sidecar 'radius' when present, else S2 evidence); None without S2.
* `Certificate._repr_html_(self) -> 'str'`  
  HTML table (statement, status, one-line evidence with the next action) for Jupyter.
* `Certificate._repr_markdown_(self) -> 'str'`  
  Markdown table (statement, status, one-line evidence with the next action) for notebooks.
  `summary()` is one sentence; `report()` is the full text (the `summary()` of 3.1); in Jupyter a Certificate renders as a statement/status/evidence table.


## Reports, diagnostics and budgets (3.2)

* `methods_paragraph(cert, style: 'str' = 'plain') -> 'str'`  
  Methods-section paragraph for `cert` (a Certificate), followed by a BibTeX entry; in style 'latex' also a `\newcommand` block with every number (numbers inside `\num{}` from siunitx).
* `estimate_seconds(dimension: 'int', model: 'str' = 'auto') -> 'float'`  
  Estimated wall seconds of S1+S2+S3 for a claim of this dimension.
* `auto_budget(dimension: 'int', model: 'str' = 'auto', factor: 'Optional[float]' = None, floor: 'Optional[float]' = None) -> 'float'`  
  Default time budget: max(floor, factor * estimate_seconds(dimension, model)); always finite. `factor` and `floor` default to AUTO_FACTOR and AUTO_FLOOR_SECONDS (read at call time).
* `diagnostics.next_action(stmt: 'dict', context: 'Optional[dict]' = None) -> 'Optional[str]'`  
  The next action for one statement record, or None when its status needs none (CERTIFIED, FAILED, CORROBORATED). Never returns an empty string for INCONCLUSIVE / NOT_CHECKED.
  Every INCONCLUSIVE / NOT_CHECKED statement carries `evidence["next_action"]` (set by `certify()`).
  `Options(budget_seconds="auto")` / `--budget auto` sets the time budget from `certify_ed.cost` (advisory: it only sets the default budget); `Options(progress=True)` / `--progress` prints one line per statement with the elapsed time (docs/presets.md).

## Exact layer

* `exact_matrix(spec, states=None) -> certify_ed.checker.ExactMatrix`  
  The declared model as an exact matrix (see ExactMatrix).
* `exact_eigenpair_radii(spec, lam, X, states=None, exact=None)`  
  Residual radii of claimed eigenpairs against the declared model, in exact arithmetic.
* `exact_recheck_lowest(spec, lam, X, states=None, next_hint=None, max_dim=4000)`  
  Independent re-check, in exact arithmetic only, of a claim 'these are the k lowest eigenpairs of the declared model' (any local space; see exact_matrix).
* `exact_recheck_sector_lowest(spec, states, gens, fixed: Dict[int, int], lam, X, next_hint=None, log=None)`  
  Exact re-check of 'lam are the len(lam) lowest eigenvalues of H in the subspace where generator i has the 1D quantum number fixed[i] (character value exp(2 pi i j / order))'. All other generators are summed over their 1D characters; the decomposition is checked to be complete (sector dimensions add up to the dimension of the fixed subspace), so non-abelian groups are allowed as long as every irrep met is one-dimensional with Gaussian character values (e.g. translations at k = 0 or pi with reflection and spin flip). X: claimed vectors in the coordinates of `states`; each must have a nonzero exact projection onto the fixed sector (Theorem 1 hypothesis), otherwise the result is INCONCLUSIVE.
* `site_permutation(spec, perm, name='site_permutation') -> certify_ed.basis.CyclicSymmetry`  
  Symmetry s -> state with digit of site i moved to site perm[i] (spins and bosons).

## Exact layer (module level)

* `exact_sectors.exact_count_below(spec, states, gens, fixed, points, log=None)`  
  Exact counts of eigenvalues of H below each point g (Fractions), restricted to the subspace with the fixed quantum numbers and summed over all other 1D irreps (decomposition completeness checked). Returns a list of {point, count, delta}: #(eig < g - delta) <= count <= #(eig < g + delta). A count of 0 proves lambda_min >= g - delta. No floating-point assumption.
* `checker.inertia_exact(M, rows_per_block: int = 256)`  
  Inertia of an exact symmetric integer matrix M (object ndarray of Python ints, or flint.fmpz_mat).
* `checker.is_hermitian_exact(ex: certify_ed.checker.ExactMatrix) -> bool`  
  W K Hermitian, checked exactly: w_r K_rc == conj(w_c K_cr) for every stored entry.

## Applications

* `apps.aklt.certify_lattice(name, thresholds=None, check_geometry=True, log=<built-in function print>)`  
  Exact eta certificate for one lattice of LATTICES. Returns a JSON-ready record including the floating-point reproduction, the certified bound sqrt(t') at the best certified threshold, and whether the criterion eta < 1/z holds (decided exactly on t' < 1/z^2).
* `apps.aklt.eta_float(g, L, C, R)`  
  Floating-point eta in reduced V coordinates (geometry check only; not a certificate).
* `apps.aklt.square_octagon_criterion(rec_par, rec_perp)`  
  4 eta_perp + 2 eta_par < 1, decided with rational upper bounds on the square roots.
* `apps.aklt.kernel.kernel_check(g: certify_ed.apps.aklt.graph.Graph, region, log=<built-in function print>, p=2147483647)`  
  
* `apps.pyrochlore.spin_half.certify_crown(n1=381414, n3=817957, margins_rel=(1e-10, 1e-09, 2e-08), log=<built-in function print>)`  
  Exact lower bound on lambda_min(H_crown). The shift g is placed a relative margin below the Lanczos estimate on a fine dyadic grid (2^-20 in K H units); if an eigenvalue is counted below it, the next, larger margin is tried. The estimate only places g: the bound g - delta is certified by the exact counts whatever its accuracy.
* `apps.pyrochlore.spin_one.printed_coupling_check(c1='0.053466', c3='0.082726', published='-1.632985', exact=True)`  
  Rigorous: the all-singlet configuration has eigenvalue -12 c1 + c17 E0(ring). E0 is enclosed by certify() (S2 + S3, standard floating-point model) and, with exact=True and python-flint, again by exact_recheck_lowest (integer arithmetic only, scaled spin-1 basis); the bound used is the exact one when available. Returns the certified upper bound on that eigenvalue and whether it lies below the published bound.
* `apps.pyrochlore.spin_one.landscape(S2, c1, c3, classes=None)`  
  Floating-point lowest eigenvalue of every pair-spin class (or of the given classes).

## Command line

```
certify-ed command line: one entry point for using the package and for reproducing the paper.

    certify-ed env                                   floating-point environment and versions
    certify-ed certify CLAIM.npz --spec SPEC.json [--kind lowest] [--exact] [-o CERT]
    certify-ed certify --from BUNDLE_DIR [--preset NAME] [--only S1,S2] [--skip S3]
                       [--budget-seconds S | --budget auto] [--budget-mb MB] [--reason TEXT]
                       [--temperatures T1,T2] [--progress]
    certify-ed import BUNDLE_DIR [same flags]        the same, bundle first (docs/producer_bundle.md)
    certify-ed statement CERT.json [--style latex] [-o FILE]   methods paragraph + BibTeX from a certificate
    certify-ed view CERT.json [-o CERT.html]         offline HTML page of a certificate (docs/viewer.md)
    certify-ed presets                               the presets and statements table (docs/presets.md)
    certify-ed spectrum MATRIX.npz [--sectors KEY]   enclose a whole spectrum (the former symveig)
    certify-ed list                                  the experiments and what they establish
    certify-ed test [PYTEST ARGS...]                 the test suite (repository checkout)
    certify-ed reproduce [--full] [--only E0,E9] [--skip E2] [--with-mutation] [--jobs N]
                         [--out DIR [--resume]]      tests + experiments + numbers into one run dir
    certify-ed numbers [--run DIR] [--manuscript DIR]

`python run.py` in the repository is `certify-ed reproduce` (quick mode; `--full` for everything).
A run directory holds manifest.json (commit, source fingerprint, environment, per-step status, time,
record paths and fingerprint), SUMMARY.md, the test log, one sub-directory per experiment record, and
the generated numbers. `--jobs N` runs experiments in parallel; `--resume` keeps finished steps.
```
