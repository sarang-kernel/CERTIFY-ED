finite stored A, x ≠ 0, μ (no magnitude hypothesis)". Counterexample (exact): A = diag(1, 2), μ = 1 + 10⁻⁸,

which fail on the previous code (verified: 2 failed before, 2 passed after). No other bound becomes tighter.
